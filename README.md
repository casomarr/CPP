# C++ bootcamp

## Goal
Master the C++ programming language by completing practical exercises and projects that cover core concepts like classes, inheritance, polymorphism, and STL (Standard Template Library).

## Key Topics Covered

1. Basic Syntax:
  - Variables, data types, loops, conditionals.
  - Functions and scope.
  - Input/output operations.

2. Object-Oriented Programming:
  - Classes and objects.
  - Encapsulation, inheritance, and polymorphism.
  - Operator overloading.
  - Friend functions and classes.

3. Memory Management:
  - Pointers and references.
  - Dynamic memory allocation (new, delete).

4. Advanced Features:
  - Templates and generic programming.
  - Exception handling.
  - Namespaces.

5. Standard Template Library (STL):
  - Containers (vectors, lists, maps, etc.).
  - Algorithms and iterators.
